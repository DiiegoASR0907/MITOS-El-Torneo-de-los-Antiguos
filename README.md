# MITOS: El Torneo de los Antiguos

Videojuego de lucha 2D inspirado en criaturas de la criptozoología, mitos y leyendas del mundo.

## Prototipo 0.1

El prototipo permite elegir tanto al luchador como al rival entre **12 personajes** del universo MITOS, con perfiles y paletas de color propias. El combate se desarrolla en el Templo del Umbral. Es una demo creada con HTML, CSS, JavaScript y Canvas 2D, sin dependencias ni instalación.

### Jugar

- Abre **[index.html](./index.html)** en un navegador moderno.
- Pulsa **Elegir personajes**, selecciona tu luchador y el rival, y después pulsa **Comenzar combate**. También puedes usar **Sorpréndeme** para recibir una pareja aleatoria.
- Bigfoot y Chupacabras ya tienen poses vectoriales animadas de reposo, movimiento, salto y ataque; los impactos y especiales incluyen destellos y energía. Es una primera pasada original en Canvas, todavía no hojas de sprites rasterizadas definitivas.
- **A / D:** moverse.
- **W** o **↑:** saltar.
- **J:** golpe.
- **K:** ataque especial.
- **L:** mantener para bloquear y reducir el daño recibido.
- En pantallas táctiles aparecen controles en pantalla.

En móvil, usa los botones táctiles; **DEFENSA** sirve para bloquear mientras lo mantienes pulsado.

También puedes publicar el repositorio con GitHub Pages para jugar desde un enlace web.

## Visión

Construir un juego de lucha accesible, con identidad visual anime, escenarios míticos, movimientos especiales y un plantel diverso de personajes legendarios. El arte actual es una primera pasada vectorial animada en Canvas; se irá refinando y extendiendo al resto del plantel.

La iteración actual añade impactos más expresivos, anillos de energía y partículas para ataques especiales, además de efectos diferenciados al bloquear.
